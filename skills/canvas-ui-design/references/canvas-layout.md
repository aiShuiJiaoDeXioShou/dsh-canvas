# 画布布局构造与核对

补充 dsh-canvas 中容易出错的布局细节，不替代 `canvas/FORMAT.md`。

## Auto Layout

- 先读取候选 Frame 的实际宽高、layout、layoutSizing、padding 和默认内容，不能只看被拉宽的实例。
- 横向/纵向布局的 `layoutSizing` 决定 fixed/hug/fill；改文字或设置主轴后重新读取最终尺寸。
- 母版应独立可用，不依靠逐页拉宽实例掩盖母版坍缩；用真实文案和较长标签检查换行、内边距、图标位置。

## 固定视口与自然内容

```text
页面根 Frame：设备尺寸，clip true，背景完整
  ├── 状态栏/导航栏（固定）
  ├── 内容视口：固定高度，clip true
  │     └── 内容 Frame：宽度固定，高度随内容（auto height / vertical layout）
  └── 底栏/操作区（固定） + Home Indicator / 安全区
```

- 长内容用视口 + 自然高度表达；不要让内容同时 fill 剩余高度又被裁切。
- 先确定导航/底栏占用再算视口；不为首屏容纳所有内容缩小字号/压窄行高。
- 检查视口/内容实际高度和最后一个子项边界；溢出时保留全部子项并检查滚动设置。
- 静态画布只表达滚动，不声称已实现运行端滚动。

## 图表与选择控件

- 百分比进度用完整轨道表示 100%，填充长度按占比计算；相对最大值/截断坐标轴要明确尺度。
- 分段选择保留独立选项和可辨识选中态；不要用文字/圆点冒充最终图形。
- 检查实际数值、合计、图例、填充比例和尺度一致。

## 图标与触控

- 图标本体与实际触控容器分开；视觉小图标也要有足够外层目标。
- 同一组图标统一网格、可见大小、线宽/端点、选中态；用基础几何自绘时不继承无关描边/颜色。
