# 素材交接

默认在 `canvas/assets/` 保存实际素材文件；设计源和页面节点仍在 `canvas/*.canvas.json`。

## 记录

- 素材 ID、用途、所在页面/区域；
- 来源：复用/用户上传/AI 生成（GPT 原生或 Codex）；
- 实际文件路径、格式、尺寸、透明通道；
- 使用的画布节点/asset 路径；
- 必要限制：裁切、清晰度、透明边缘、仅特定尺寸使用。

单项修改可随文件说明；批量交付可用 `canvas/design/manifest.json` 的 `assets` 数组。生成素材保留采用的 prompt 和参考，已交付版本另存后再修改。

## 交付

提供实际文件、尺寸、用途和必要限制，让开发能直接找到使用位置。只交付素材时不需要单独审批表；已放入画布不等于视觉合适，最后仍要查看实际画面。

## 完成

素材文件、用途和接入位置一致；缺失/替代项明确说明。
