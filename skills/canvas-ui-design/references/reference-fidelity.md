# 参考落实与视觉校准

把用户选定的参考转成画布上的明确约定，再构建原生页面。适用于风格图落地、截图复刻、沿用旧稿补页和视觉修订。

## 确定参考作用

- 区分功能证据、视觉基准与用户反馈：录屏中的真实操作支持行为结论；用户采用的图片是视觉基准，图中文字/虚构数据按实际需求修正并记录。
- 有画布节点就读取相关节点和共享组件；只有图片时把尺寸、色值、字体判断标为估计，不声称精确像素匹配。
- 用户只要求“借颜色/风格”时，不借机替换布局；忠实还原与风格借鉴分开。

## 忠实还原

用户要求复刻、照图制作或采用生成图进入画布时，默认保留参考范围内的区块、顺序、位置、大小比例、文字层级、配色、材质、图标、关键素材和状态。不能自行删模块、重排、换素材或“优化”成另一版。参考中不清楚的细节先按现有证据确定，仍未知的标为估计。

字体不可用、源素材缺失、生成偏差或工具限制属于待处理差异；修正错字/业务数值/截图外框/可用性问题时说明依据和影响。不要未经验证宣称“100% 还原”。

## 形成视觉约定

在 `canvas/design/brief.md` 或 `style-contract.md` 记录本轮相关项：

| 对象 | 内容 |
| --- | --- |
| 布局与文字 | 画幅/倍率、边距、密度、字号/行高/字重、字体回退、固定区/滚动区 |
| 颜色与材质 | 背景/正文/元信息/动作/状态角色、透明度、圆角、边框、渐变 |
| 控件与状态 | 按钮/输入/列表/选择控件结构，选中/未选中和必要反馈 |
| 图标与素材 | 图标家族、线性/面性、网格/可见大小、描边；关键头像/封面/分类图形 |
| 保留与差异 | 必须还原的特征、允许变化的部分、替代项、未知参数 |

页面行为和视觉约定分开；不要把实现限制/待验证事项写成页面里的提示卡。

## 先校准再扩展

1. 选 1–2 个覆盖主要布局/图标/控件的代表页，先做母组件和代表页。
2. 从参考中定位本轮屏幕内容，排除画外标题/设备外壳/展示阴影，按目标画幅归一化；检查区块完整性、位置/尺寸、间距、字体换行、颜色和状态。
3. 用实际节点核对 Auto Layout、母组件、实例缩放和滚动结构；先改共享来源，再复看代表页。
4. 对实际页面与参考同尺寸并排，必要时叠加/差异图核对；完成代表页后逐页核对其余交付页面，不以代表页通过代替整套。
5. 在报告中写“参考特征 → 实际实现 → 剩余差异”；未解决偏差继续列出。

美观程度仍需看图判断；颜色、几何、数据检查只覆盖可计算部分。
