# Canvas Design Foundation

本插件的跨平台移动端设计起点，数值为逻辑像素和本地约定，不是 Apple/Figma 官方强制标准。已有品牌、组件库和用户明确要求优先。

## 默认设备与系统区域

- 未指定机型的新项目：**iPhone 16，393×852 逻辑点**，1 点 = 1 画布单位。用户指定其他 iPhone/平台或已有画板时沿用其规格；同一主流程不混用设备。
- 正式页面根 Frame 四角圆角为 0，背景不透明并铺满；不加设备外壳、外部阴影或圆角屏幕遮罩。卡片/按钮内部圆角不受影响。
- 默认使用 iOS 状态栏、适用底部栏和 Home Indicator；优先使用画布内置的 `ios-status-bar` / `ios-nav-bar` / `ios-tab-bar`。系统图形用形状绘制，不用 emoji/文字替代。
- 状态栏、导航栏、滚动内容、底部导航/操作和安全区分开；安全区只消费一次。长内容用固定视口 + 自然高度/滚动表达，不拉长设备画板。
- iPhone 15 390×844 作为兼容选项；已有 390 文档不自动迁移。

## 字体、间距与色彩

- 默认字体：iOS 系统字体；中文使用系统字体回退。用户指定字体优先。
- 语义角色沿用现有 M3/iOS：display / heading / title / subtitle / body / bodySm / caption 等（以 `src/shared/design-system.ts` 为准）。
- 间距阶梯：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48；页面边距、section gap、card padding 由预设控制。
- 颜色用 primary/onPrimary、surface/onSurface、error/onError、outline 等语义角色；品牌色、状态色和装饰色分开。

## 内容关系与自然滚动

按内容关系选择间距：关联越强越靠近，组间留白大于组内；同类关系保持一致。

| 内容关系 | 默认起点 | 示例 |
| --- | --- | --- |
| 强关联细节 | 4–8 | 图标与短标签 |
| 同话题连续内容 | 8 | 卡片标题与摘要 |
| 切换内容组 | 16 | 不同模块 |
| 新任务/新话题 | 24 | 独立业务区块 |

卡片不因外形独立就强制拉大外间距。嵌套 Auto Layout 表达消息组/卡片内容层，复用间距变量；不要逐页拼数值。手机画板保持设备尺寸，滚动内容自然增高；导航/输入栏在滚动区域外。

## 四种风格，共用组件契约

| 参数 | Neutral（默认） | Minimal | Soft | Compact |
| --- | --- | --- | --- | --- |
| 页面水平边距 | 16 | 20 | 20 | 12 |
| 卡片 / 按钮圆角 | 12 / 12 | 8 / 8 | 20 / 16 | 8 / 8 |
| 区块间距 | 16 | 24 | 20 | 12 |
| 卡片内边距 | 16 | 16 | 20 | 12 |
| 阴影 / 密度 | 轻 / 标准 | 无 / 疏 | 柔和 / 疏 | 无 / 紧凑 |

预设控制外观，不分别创建四套组件库。Compact 缩小留白，不缩小触控目标；Soft 只让装饰柔和，正文保持足够对比。

Button：Primary/Secondary/Outline/Text，Small/Medium/Large，Default/Pressed/Focused/Disabled/Loading。Input 保留 label、value、help/error、focus、disabled。导航保留选中态、返回路径和页面状态；Dialog/Sheet 定义关闭与取消。重要状态不能仅靠颜色表达。

## 可用性与适配

- 正文对比度至少 4.5:1，大文本至少 3:1；必要非文本边界/状态至少 3:1。
- 交互区域至少 44×44（iOS）；视觉图标可更小，但外层触控容器要足够。
- 容器宽度：<600 单栏，600–839 可单/双栏，≥840 可多栏/侧导航；这是起点，不按设备名判断。
- 导航/底栏内容高度与安全区分开；由明确布局层消费 inset，避免重复 SafeArea/padding。
- 动效简短一致；静态画布不声称已实现真实交互。
