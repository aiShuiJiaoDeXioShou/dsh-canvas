# 风格适配

用于用户明确要求借鉴/改版某些参考风格。**照图还原**以及采用已确认生成图默认走 [参考落实](../references/reference-fidelity.md)，不自动套用本工作流的自由度。

## 先确定范围

看参考图或用户描述，明确只借鉴颜色/氛围，还是也调整圆角、字体、密度、布局。未指定强度时采用 Standard，但保留已有项目布局，除非用户要求布局变化。

| 强度 | 可调整范围 |
| --- | --- |
| Light | 主色、装饰色、背景、阴影 |
| Standard | Light + 圆角、字体层级、密度、卡片外观 |
| Creative | Standard + 本轮授权范围内的布局和组件外观 |

## 写入方式

1. 读取当前设计系统和 Foundation 预设；区分已有项目规范、用户明确要求、参考估计值。
2. 只覆盖需要改的字段：颜色、圆角、密度、阴影；不因为换风格顺带改错误色/状态色/字体（用户未要求时）。
3. 用 `canvas_template foundation` / styles / 页面节点实际修改；保留用户锁定或明确保留的项。
4. 注意触控、可读性、安全区和交互规则不能被降低；低对比/小点击目标要改成可用的等效表达。
5. 修改后复看受影响页面，比较视觉特征，不能把 token 校验通过当作风格还原成功。

## 完成

记录采用的参考特征、改变的字段、保留项和未解决差异；局部修改不重排无关页面。
