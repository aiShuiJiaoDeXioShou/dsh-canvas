# 修改与回归

先定位用户要改的是 token、共享组件、单个实例还是页面布局。读取当前画布、选区、styles/components 和已有改动；沿用现有规范，不因进入本技能重置为 Neutral。

## 修改原则

- 局部颜色/文案/尺寸改动只动受影响节点，不重排页面。
- 共享组件/样式修改先确认引用范围；只改某页时用局部覆盖，避免影响所有实例。
- 全局换风格先按 [风格适配](style-adaptation.md) 确认范围，再统一更新；不要静默覆盖锁定/用户明确保留的字段。
- 较大改版保留已交付版本依据（复制 Frame 或记录 revision），不覆盖未知人工改动。
- 修改后用 `canvas_read`/实际渲染复看受影响页面和适用状态；需要时运行 `canvas_audit`。

## 回归

- 受影响组件/实例：检查宽高、内边距、文字换行、图标和状态；
- 受影响页面：检查截断、遮挡、滚动、空/错误状态；
- 未验证的真实交互明确标注，不声称已通过运行验收。

## 完成

只处理本轮影响范围；记录实际差异和剩余问题。
